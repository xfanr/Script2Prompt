# 独立存储与 WebDAV

本地 `localStorage` 使用 `script2prompt.files.v1.` 前缀，分别保存 `settings.json`、`ungrouped.json`、`groups/<编码后的分组ID>.json`、`directory`、`ui` 和 `sync`。`sync` 只包含按目标隔离的 ETag、分组名称、待删除文件与最近完整同步时间，不包含剧本正文或密码。

首次加载会迁移旧的 `script2prompt.appState.v1`，旧条目保留不再更新。保存事务使用仅包含变动记录的临时日志；中断后回滚。空间不足时显示持久错误提示，可以重试或导出备份。检测到其他标签页保存时要求刷新，避免用旧页面覆盖新数据。

## 云端目录

WebDAV 地址直接指向同步目录，不再追加 `script2prompt/` 等目录名。此地址下保存 `settings.json`、`ungrouped.json` 和 `groups/`。分组名称不参与文件路径，归档仍保留独立文件。分组引用提示词的三个固定槽位，下载时映射为当前设置中的方案 ID。

上传处理全部本地文件，未变化内容跳过；云端独有分组保留。覆盖和删除均使用读取时的强 ETag 作为条件，确认后若文件又发生变化会失败并提示重试。服务器缺失强 ETag 时允许读取和新建，拒绝更新或删除现有文件。跨域服务器需允许 GET、PUT、DELETE、PROPFIND、MKCOL，允许 Authorization、Content-Type、Depth、If-Match、If-None-Match 请求头，并暴露 ETag 响应头。代理必须保留条件请求语义。参考 [WebDAV RFC 4918](https://www.rfc-editor.org/rfc/rfc4918)。

下载先读取、校验并复核整个批次，确认后一次保存到本地。同 ID 分组和未分组内容整体替换，本地独有分组保留，全局设置替换。不使用普通备份导入的 ID 重新生成逻辑。若一个单集 ID 同时出现在多个分组，整批下载停止，需要先完成云端移组或解决重复。

本地删除只有在对应目标曾有同步基线时才进入待删除列表。上传未完成时不会继续删除云端原分组；取消删除会保留记录。多文件远程写入不具备整批原子性：逐文件展示结果，重试会跳过已经成功的相同内容，仅全部完成时更新完整同步时间。

## 旧云端文件

在 WebDAV 设置中展开“迁移旧版单文件”，确认原文件名后直接拆分到当前同步目录。目录中生成 `settings.json`、`ungrouped.json` 和 `groups/`；不会再创建额外的外层文件夹。原文件、本地数据都保留；完成后点击下载。迁移可继续写入先前失败的文件；已有新格式文件必须与迁移输出完全相同，任何不同内容都停止迁移。迁移本身不建立本地剧本的同步基线，避免误把旧本地内容视为已与云端一致。

目录列表先通过 Depth 0 获取服务器自身目录标识，再校验 Depth 1 的直接子项，以兼容反向代理返回后端目录路径。实际读写始终使用配置的公开地址，不跟随列表中的外部地址。

普通备份导入导出仍为原来的整体 JSON，便于离线备份与恢复；不作为日常保存格式。

## 验证

运行 `npm.cmd run build` 进行编码、类型与构建检查。

运行 `npm.cmd run dev -- --host 127.0.0.1`，在浏览器打开 `/tests/storage-webdav.html`。测试使用独立内存 Storage 和模拟 fetch，不读写实际用户存储或 WebDAV。页面输出每个用例结果，自动化可读取 `window.testResults`。测试入口不属于生产构建。

覆盖迁移与中断恢复、按分组写入、跨组移动、存储配额失败、两设备冲突、条件写入竞态、删除确认和恢复、下载批次校验、网络与认证错误、提示词槽位映射及旧云端文件迁移重试。
